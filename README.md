# 🌱 Crop Recommendation System

An AI-powered Crop Recommendation System built using **Python, Machine Learning, Random Forest, and Streamlit**.

The application recommends a suitable crop based on various soil and environmental conditions such as **Nitrogen (N), Phosphorus (P), Potassium (K), Temperature, Humidity, Soil pH, and Rainfall**.

The machine learning model is trained using a **Random Forest Classifier**, while Streamlit provides an interactive and user-friendly web interface.

### ✨ Features

* 🌾 Crop recommendation based on soil and weather conditions
* 🤖 Random Forest Machine Learning model
* 🌡️ Temperature and humidity analysis
* 🧪 NPK and soil pH inputs
* 🌧️ Rainfall-based prediction
* 📊 Prediction confidence
* 🌱 Modern agriculture-themed Streamlit interface
* ⚡ Real-time crop prediction

### 🛠️ Technologies Used

Python • Streamlit • Scikit-learn • Pandas • NumPy • Joblib • Machine Learning
